02 How it works Como funciona Cómo funciona

Two files. One glance. Dois arquivos. Um olhar. Dos archivos. Una mirada.

Each agent appends to a shared status file when it starts and removes itself when it ends. The tray icon reads that file four times per second and colors itself accordingly. That's the entire architecture. Cada agente acrescenta uma entrada em um arquivo de status compartilhado ao iniciar e se remove ao terminar. O ícone na bandeja lê esse arquivo quatro vezes por segundo e se colore conforme. Essa é a arquitetura inteira. Cada agente añade una entrada a un archivo de estado compartido al iniciar y se elimina al terminar. El ícono en la bandeja lee ese archivo cuatro veces por segundo y se colorea según corresponda.
